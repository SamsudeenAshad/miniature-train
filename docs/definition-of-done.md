# Definition of done tracker (SRS 19.1)

Check only when evidence is linked. Unchecked = future obligation, not done.

- [ ] FR/NFR/ML behavior implemented with linked verification evidence.
- [ ] Source, config, schemas, cards, manifests version-controlled.
- [ ] Dataset-to-model and incident-to-action lineage traversable + exportable.
- [ ] Serving package pinned, trusted, reproducible, schema-compatible.
- [ ] Failed/missing/stale/low-volume evidence triggers documented gate behavior.
- [ ] Learned AIOps compared with deterministic baseline on frozen holdout.
- [ ] Grouping/diagnosis retain evidence and acknowledge uncertainty.
- [ ] No prohibited runbook executes; duplicate/stale-worker tests pass.
- [ ] Rollback restores behavior and reconciles desired state.
- [ ] Timed restore checked against digests.
- [ ] Limitations, failed targets, pending SLO, exceptions visible.
- [ ] Second contributor repeats setup + demo from docs alone.
- [ ] R1/R2 pilot acceptance recorded; R3 tracked separately.
